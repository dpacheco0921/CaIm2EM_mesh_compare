# Data and code to generate and process meshes/surfaces of persistent response types

# Organization of data
- 1) densities: a folder with image files (*.nrrd) with voxel density of activity cluster types.
- 2) meshes: a folder with meshes generated using densities of persistent response type.
- 3) synapses: folder where to save the synapse table, which also contains the logical table of synapses inside meshes of the persistent response type.
